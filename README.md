# TokenTracker Personal

A personal token usage tracker for multiple computers. It collects usage locally, combines devices through your own backend, and provides a private dashboard and an optional public usage page.

- Token totals, estimated costs, model breakdowns, sessions and activity history.
- Device authorization, sync status, pause and resume controls.
- An optional public page with your nickname and avatar, anonymous display and immediate withdrawal.
- A shared, versioned price catalog for the local collector and backend, with offline fallback and owner-controlled updates.
- Achievements, yearly review, limits, widgets, IP checks and provider status tools.
- Bot in the native menu bar or system tray, with automatic appearance.

Existing-account sign-in and device authorization remain available. Registration is closed on the personal deployment. Commercial plans, checkout, membership promotion, skill management, desktop pets and third-party analytics are removed from the personal product.

See [personal deployment and updates](docs/personal-instance.md) for installation, price updates and compatibility. Local collectors require this edition to consume the shared catalog; existing clients keep their device synchronization protocol.
